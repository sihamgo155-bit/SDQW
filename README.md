# CIA COMMAND PORTAL — النسخة العربية المحسّنة

بوابة خيالية لمجتمع Roleplay مستوحى من أجواء الاستخبارات والألعاب. هذا مشروع ترفيهي مستقل وليس موقعاً حكومياً أو تابعاً لوكالة CIA.

## المزايا
- واجهة عربية RTL بتصميم أسود وأحمر متجاوب.
- اختبار QCM واستمارة تقديم.
- طلب منفصل للانضمام إلى فريق الإدارة.
- لوحة إدارة تجريبية: مراجعة الطلبات، الأعضاء والرتب، المهام، الإعلانات والإعدادات.
- سلم الرتب: `Agent-1`, `Agent-2`, `Agent-3`, `Agent-4`, `Agent-5`, `Senior Agent`, `Specialist`, `Beta`, `Alpha`, `Naib Alpha`, `Deputy Director`, `Director`.
- تكامل عميل اختياري مع Supabase عبر المفتاح العام فقط.
- إرسال رقم مرجعي مطابق للرقم المحفوظ في قاعدة البيانات.
- رسائل أوضح عند فشل الحفظ؛ لا يتم عرض نجاح إذا أعادت قاعدة البيانات خطأ.

## التشغيل المحلي
1. فك ضغط ZIP.
2. افتح المجلد في VS Code وشغّل Live Server، أو نفّذ `python -m http.server 8000`.
3. افتح `http://localhost:8000`.
4. في Demo Mode اضغط «دخول الإدارة» واستخدم الرمز `1937`.
5. **تحذير:** Demo Mode يحفظ البيانات في المتصفح الحالي فقط. لن تظهر الطلبات على جهاز آخر.

## إعداد Supabase
1. أنشئ مشروع Supabase.
2. شغّل `supabase/schema.sql` في SQL Editor.
3. أنشئ حساباً عبر Supabase Auth.
4. عيّن أول مدير عبر SQL باستخدام UUID الصحيح لحساب Auth، كما هو موضح في نهاية ملف SQL.
5. في `config.js` ضع `mode: 'supabase'` و`supabaseUrl` و`supabaseAnonKey` (المفتاح العام/publishable فقط).
6. افتح الموقع عبر خادم محلي أو استضافة HTTPS، ثم سجّل الدخول ببريد وكلمة مرور حساب الإدارة.
7. اختبر إرسال طلب من متصفح آخر، ثم افتح لوحة الإدارة واضغط «تحديث».

## استكشاف مشكلة «الطلب لا يصل إلى الإدارة»
- تأكد أن `config.js` ليس على `mode: 'demo'`.
- تأكد أن `supabaseUrl` و`supabaseAnonKey` صحيحان وأن مكتبة Supabase محمّلة.
- تأكد من تشغيل أحدث `schema.sql` دون أخطاء.
- افتح Supabase Table Editor وتحقق من صف جديد في `applications` أو `admin_requests`.
- إذا ظهر صف في الجدول ولا يظهر في لوحة الإدارة، افحص تسجيل دخول المدير، وجدول `admin_roles`، وسياسات RLS، وأخطاء الطلبات في أدوات المطور.
- إذا فشل الإرسال، ستظهر رسالة خطأ؛ لا تعتبر الطلب محفوظاً ما لم تظهر رسالة النجاح.

## حدود الأمان والتكامل الحالي
- `1937` وLocal Storage للتجربة فقط، وليس نظام مصادقة.
- لا تضع `service_role` أو أي سر خادمي في `config.js` أو ملفات الواجهة.
- طلب الإدارة المقبول لا يمنح صلاحية Admin تلقائياً. تعيين دور إداري حقيقي يجب أن يتم بعملية خادمية موثوقة مع التحقق من صلاحية المدير الحالي.
- تقييم QCM الحالي داخل JavaScript؛ لا تستخدم نتيجته لاتخاذ قرار إنتاجي قبل نقل الأسئلة والإجابات الصحيحة والتصحيح إلى خادم/Edge Function.
- تتبع الطلبات عبر Supabase غير متاح للعامة حالياً، لتجنب فتح قراءة بيانات الطلبات للجميع؛ يحتاج إلى Edge Function تتحقق من المرجع بطريقة آمنة.
- ملف SQL نقطة بداية؛ لم يتم ربط المشروع بحساب Supabase حقيقي أو اختبار سياسات RLS في مشروع فعلي.

## اختبار يدوي مقترح
1. في Demo Mode، أرسل طلباً ثم راجعه من لوحة الإدارة في المتصفح نفسه.
2. جرّب قبول ورفض الطلبات، وتغيير الرتب، وإنشاء مهمة وحذفها.
3. أعد تحميل الصفحة وتحقق من بقاء البيانات المحلية.
4. في Supabase Mode، أرسل طلباً من جهاز آخر، وتأكد من ظهوره في جدول قاعدة البيانات.
5. سجّل الدخول كمدير وتأكد من أن الطلب يظهر في لوحة الإدارة.
6. جرّب حساباً غير إداري للتأكد من أنه لا يستطيع قراءة الطلبات أو تعديلها.

## الملفات
- `index.html` — واجهة الموقع.
- `styles.css` — التصميم.
- `app.js` — منطق الواجهة ووضع التجربة وتكامل Supabase.
- `config.js` — إعدادات العميل العامة.
- `supabase/schema.sql` — مخطط قاعدة البيانات وسياسات RLS.


## تنبيه مهم حول وصول الطلبات والأمان
- وضع `demo` يحفظ البيانات داخل `localStorage` في المتصفح الحالي فقط؛ لا يمكن للمدير رؤيتها من جهاز آخر.
- لتصل طلبات الانضمام وطلبات الإدارة إلى لوحة المدير، يجب إنشاء مشروع Supabase وتشغيل `supabase/schema.sql` وضبط `config.js` على `mode: 'supabase'` مع Project URL و anon key وإعداد سياسات RLS وSupabase Auth.
- تمت إزالة رمز الدخول العام `1937` من واجهة الموقع وتعطيل الدخول المحلي التجريبي. في وضع demo ستظهر رسالة تطلب إعداد Supabase بدلاً من فتح لوحة الإدارة.
- لا تضع `service_role` key في `config.js` أو في ملفات الواجهة الأمامية.
- هذه الحزمة لا تدّعي أن إعداد Supabase قد تم؛ يجب اختبارها بعد إدخال بيانات مشروعك.


## تصحيح الواجهة
- تم إصلاح خطأ JavaScript كان يحاول الوصول إلى عنصر تسجيل دخول تجريبي محذوفاً، وقد يمنع تشغيل بقية الواجهة.
- تم توضيح حقل كلمة المرور ليظهر بوضوح ككلمة مرور/رمز سري لحساب الإدارة. التحقق الفعلي يتم عبر Supabase Auth، وليس عبر كود ثابت داخل ملفات الموقع.
- الطلبات لن تظهر على جهاز المدير إلا بعد إعداد `config.js` وربط Supabase Auth وRLS وتشغيل `supabase/schema.sql`. لا يمكن تفعيل التخزين المشترك دون بيانات مشروع Supabase الخاص بك.
